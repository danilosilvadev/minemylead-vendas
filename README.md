# MineMyLead · Portal do vendedor

Página de GitHub Pages com tudo para vender o MineMyLead.

- `index.html` — o portal (aulas, habilidades, slides, infográficos, kit, vídeos, imagens, textos)
- `habilidades/` — curso de 12 lições, personas, quiz, ficha de autoavaliação, plano de 14 dias
- `slides/` — duas apresentações (cliente e treinamento); PDFs em `assets/pdf/`
- `kit/` — o kit do vendedor (fonte: `MineMyLead-app/docs/sales-kit`)
- `assets/` — vídeos, PDFs, infográficos, imagens, logos, pôsteres
- `tools/` — geradores (Python) e render (node + chromium): `build_portal.py`, `build_skills.py`, `build_slides.py`, `build_infographics.py`, `render.mjs`

Não indexada por buscadores (`noindex` + `robots.txt`). Material interno do time de vendas.

# MineMyLead · Portal do vendedor

Página de GitHub Pages com tudo para vender o MineMyLead: 4 aulas em vídeo, kit do vendedor (página e PDF), vídeos de marketing, carrossel e logos para baixar, textos prontos.

- `index.html` — o portal
- `kit/` — o kit do vendedor (fonte: `MineMyLead-app/docs/sales-kit`)
- `assets/` — vídeos, PDF, imagens, logos, pôsteres

Não indexada por buscadores (`noindex` + `robots.txt`). Material interno do time de vendas.
